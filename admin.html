⚙️ Управление ролями

Чтобы назначить кого-то администратором вручную, выполни SQL-запрос в Supabase → SQL Editor: 

UPDATE public.profiles
SET role = 'admin'
WHERE nickname = 'НИК_ИГРОКА';

Для суперадмина (полные права): 

UPDATE public.profiles
SET role = 'superadmin'
WHERE nickname = 'НИК_ИГРОКА';
